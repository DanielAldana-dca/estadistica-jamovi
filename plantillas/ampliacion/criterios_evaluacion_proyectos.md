# Rúbrica común para proyectos

Califica cada criterio de 0 a 4: 0 = ausente/incorrecto, 1 = muy incompleto, 2 = parcialmente correcto, 3 = correcto, 4 = completo y justificado.

| Criterio | Qué se evalúa | Puntuación (0–4) |
|---|---|---:|
| Pregunta | Es clara, relevante y responde a un objetivo definido | |
| Datos y diseño | Describe origen, filas, variables, selección y estructura | |
| Limpieza | Identifica errores/faltantes y documenta decisiones | |
| Método | La técnica coincide con pregunta, variables y diseño | |
| Supuestos | Revisa supuestos importantes y toma decisiones razonables | |
| Ejecución en jamovi | Archivo editable, variables configuradas, análisis reproducible | |
| Interpretación | Explica magnitud, incertidumbre y valor p cuando proceda | |
| Gráficos/tablas | Son legibles, pertinentes y etiquetados | |
| Conclusión | No exagera causalidad ni generalización | |
| Reproducibilidad | Entrega OMV, datos, diccionario y bitácora | |

**Máximo:** 40 puntos. La puntuación total es una guía; un error grave de diseño o interpretación no debe ocultarse tras un promedio alto. Define previamente cualquier criterio mínimo obligatorio.
