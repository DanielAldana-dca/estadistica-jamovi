## Formato

- **PNG** para gráficos y capturas
- **SVG** para diagramas vectoriales
- **JPG** solo cuando el tamaño sea crítico

## Nombres

Usa nombres descriptivos:
- `histograma-ansiedad.png`
- `boxplot-por-grupo.png`
- `interaccion-2x2.png`
