# Estadística con jamovi: De Cero a Profesional

Repositorio de aprendizaje práctico basado en el libro **"Learning Statistics with jamovi"** de Danielle Navarro y David Foxcroft.

## 🎯 Objetivo

Aprender probabilidad y estadística desde cero hasta nivel profesional usando jamovi.

## 📚 Libro base

- **Título:** Learning Statistics with jamovi
- **Autores:** Danielle Navarro y David Foxcroft
- **URL:** https://lsj.readthedocs.io

## 🛠️ Herramientas

- jamovi: https://www.jamovi.org
- Módulos: distrACTION, esci, jpower, GAMLj, Rj

## 📖 Cómo usar este repositorio

1. Lee cada lección en orden
2. Abre jamovi y replica cada ejemplo
3. Guarda tu archivo .omv como evidencia
4. Completa los proyectos
5. Usa las plantillas para reportar
