# Conjuntos de datos del curso

Aquí se encuentran todos los datasets usados en las lecciones.

## Datasets incluidos

| Archivo | Descripción | Variables | Lecciones |
|---------|-------------|-----------|-----------|
| `dataset-ejemplo.csv` | Datos básicos de ejemplo | id, grupo, edad, genero, pre, post | 1-3 |
| `ansiedad.csv` | Puntuaciones de ansiedad | id, grupo, ansiedad_pre, ansiedad_post | 4-5, 11 |
| `notas.csv` | Notas y hábitos de estudio | id, horas, asistencia, motivacion, nota | 12 |
| `metodos.csv` | Comparación de 3 métodos | id, metodo, nota | 13 |
| `factorial.csv` | Diseño 2x2 | id, metodo, genero, nota | 14 |
| `cuestionario.csv` | 12 ítems de escala | id, item1-item12 | 15 |
| `fumar.csv` | Nivel educativo y hábito | id, nivel, fuma | 10 |

## Cómo cargar en jamovi

1. Abre jamovi.
2. `Data > Open > Browse`.
3. Selecciona el CSV.
4. Verifica los tipos de variables.

## Atribución

- Los datasets marcados como **sintéticos** son ficticios y creados para el curso.
- Los datasets reales incluyen la fuente original en su descripción.
