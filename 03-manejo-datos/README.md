# Preparación y calidad de datos

## Objetivo
Aprender a inspeccionar, limpiar y documentar un conjunto de datos sin alterar silenciosamente la evidencia.

## Lección
1. [Limpieza y calidad de datos](01_limpieza_calidad_datos.md)

## Práctica
Utiliza `00-recursos/datasets/datos_limpieza_intencional.csv`. Identifica valores ausentes, categorías inconsistentes y valores imposibles. Antes de corregir cualquier valor, documenta el problema, la decisión y la razón. No inventes datos para rellenar ausencias.
