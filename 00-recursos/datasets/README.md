# Conjuntos de datos del curso

Todos los archivos que incluyen `sinteticos` en el nombre contienen datos ficticios generados para practicar. No son datos de investigación real ni deben citarse como evidencia empírica.

## Archivos
- `datos_estudiantes_sinteticos.csv`: variables numéricas y categóricas para descriptiva, gráficos, correlación y regresión.
- `datos_pre_post_sinteticos.csv`: mediciones pareadas y grupo para practicar comparaciones.
- `datos_categoricos_sinteticos.csv`: variables categóricas para tablas de contingencia y chi-cuadrado.
- `datos_binomial_sinteticos.csv`: ensayos y conteos para explorar un proceso binomial.
- `datos_dados_sinteticos.csv`: resultados de tiradas para comparar frecuencias relativas con probabilidades teóricas.
- `datos_limpieza_intencional.csv`: conjunto deliberadamente imperfecto para practicar auditoría de datos.

Consulta el [diccionario de datos](diccionario_datos.md) antes de analizar y los [resultados de referencia](resultados_referencia.md) después de intentarlo por tu cuenta.
