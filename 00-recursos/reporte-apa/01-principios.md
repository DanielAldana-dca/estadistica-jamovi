# Principios generales del reporte APA

## Reglas básicas

1. **Claridad ante todo**: el lector debe entender sin ambigüedad.
2. **Precisión numérica**: usa decimales consistentes.
3. **Sin interpretación en Resultados**: interpreta en Discusión.
4. **Estadísticos en cursiva**: *M*, *SD*, *t*, *F*, *p*, *r*.
5. **Valores p con 3 decimales**: *p* = .042, no *p* = .04.
6. **p < .001** para valores muy pequeños.
7. **Nunca p = .000**.

## Símbolos y formato

| Símbolo | Uso |
|---------|-----|
| *M* | Media |
| *SD* | Desviación estándar |
| *N* | Tamaño total |
| *n* | Tamaño de subgrupo |
| *t* | Estadístico t |
| *F* | Estadístico F |
| *χ²* | Chi-cuadrado |
| *r* | Correlación |
| *R²* | Varianza explicada |
| *d* | d de Cohen |
| *p* | Valor p |

## Reglas de redacción

- Tiempo pasado: "se encontró", "se observó"
- Voz activa cuando sea posible
- Sin juicios de valor: no digas "resultado sorprendente"
- Cita el estadístico, grados de libertad y p

## Ejemplo de estructura

> "Se compararon las medias de ansiedad entre el grupo control y el experimental mediante una prueba t de muestras independientes. El grupo experimental (*M* = 32.5, *SD* = 6.2) mostró menor ansiedad que el control (*M* = 45.1, *SD* = 7.8), *t*(98) = 4.21, *p* < .001, *d* = 0.85."

## Buenas prácticas adicionales

- Reporta el valor exacto de *p* cuando sea posible; usa *p* < .001 para valores menores que .001, nunca *p* = .000.
- Incluye grados de libertad, tamaño del efecto e intervalo de confianza cuando corresponda al análisis.
- No conviertas automáticamente una asociación en una afirmación causal.
- Los ejemplos numéricos de esta guía son ilustrativos: reemplázalos por los resultados reales de tu análisis.
- Consulta las normas APA 7 de tu institución para detalles de formato y redondeo.
