# Cómo reportar pruebas t

## Prueba t independientes

> "Se compararon las medias de [variable] entre [grupo 1] y [grupo 2] mediante una prueba t de muestras independientes. El grupo [X] (*M* = ___, *SD* = ___) obtuvo [mayor/menor] [variable] que el grupo [Y] (*M* = ___, *SD* = ___), *t*(gl) = ___, *p* = ___, *d* = ___."

### Ejemplo

> "Se compararon las medias de ansiedad entre el grupo control y el experimental mediante una prueba t de muestras independientes. El grupo experimental (*M* = 32.5, *SD* = 6.2) mostró menor ansiedad que el control (*M* = 45.1, *SD* = 7.8), *t*(98) = 4.21, *p* < .001, *d* = 0.85. Esto indica una diferencia significativa con un tamaño del efecto grande."

## Prueba t pareadas

> "Se comparó la ansiedad antes y después de la intervención mediante una prueba t de muestras pareadas. La ansiedad disminuyó significativamente de antes (*M* = 45.2, *SD* = 12.3) a después (*M* = 32.5, *SD* = 10.8), *t*(49) = 8.42, *p* < .001, *d* = 1.19."

## Prueba t una muestra

> "La altura media de la muestra (*M* = 168.2, *SD* = 9.5) difirió significativamente de la media poblacional de 170 cm, *t*(99) = -1.89, *p* = .031, *d* = -0.19."
