# Cómo reportar ANOVA

## ANOVA de un factor

> "Se realizó un ANOVA de un factor para comparar [variable] entre [número] grupos. El efecto de [factor] fue [significativo/no significativo], *F*(gl1, gl2) = ___, *p* = ___, *η²* = ___. Las comparaciones post hoc con la corrección de Tukey indicaron que [interpretación]."

### Ejemplo

> "Se realizó un ANOVA de un factor para comparar las notas entre tres métodos de enseñanza. El efecto del método fue significativo, *F*(2, 147) = 6.82, *p* = .001, *η²* = .085. Las comparaciones post hoc con la corrección de Tukey indicaron que el método A (*M* = 78.5, *SD* = 10.2) superó significativamente al método B (*M* = 71.3, *SD* = 11.1, *p* = .002) y al método C (*M* = 70.8, *SD* = 9.8, *p* = .001). No hubo diferencias entre B y C (*p* = .892)."

## ANOVA factorial

> "Se realizó un ANOVA factorial 2 × 2. El efecto principal de [factor 1] fue [significativo/no], *F*(gl1, gl2) = ___, *p* = ___, *η²* = ___. El efecto principal de [factor 2] fue [significativo/no], *F*(gl1, gl2) = ___, *p* = ___, *η²* = ___. La interacción entre ambos fue [significativa/no], *F*(gl1, gl2) = ___, *p* = ___, *η²* = ___."

## ANOVA de medidas repetidas

> "Se realizó un ANOVA de medidas repetidas para comparar [variable] en [número] momentos. El efecto del tiempo fue significativo, *F*(gl1, gl2) = ___, *p* = ___, *η²* = ___."
