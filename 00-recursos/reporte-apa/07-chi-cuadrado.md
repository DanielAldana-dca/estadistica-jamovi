# Cómo reportar chi-cuadrado

## Fórmula

> "Se realizó una prueba de independencia chi-cuadrado para examinar la relación entre [var1] y [var2]. La relación fue [significativa/no significativa], *χ²*(gl, *N* = ___) = ___, *p* = ___, *V* de Cramer = ___."

## Ejemplo

> "Se realizó una prueba de independencia chi-cuadrado para examinar la relación entre nivel educativo y hábito de fumar. La relación fue significativa, *χ²*(2, *N* = 200) = 8.42, *p* = .015, *V* = .21. Esto indica una asociación pequeña pero significativa entre ambas variables."

## Bondad de ajuste

> "Se realizó una prueba de bondad de ajuste chi-cuadrado para comparar las frecuencias observadas con las esperadas. La diferencia fue [significativa/no significativa], *χ²*(gl, *N* = ___) = ___, *p* = ___."

*Nota.* *χ²*(2) = 8.42, *p* = .015.
