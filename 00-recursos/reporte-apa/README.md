## Estructura de un informe APA

1. Título
2. Resumen (abstract)
3. Introducción (contexto y objetivos)
4. Método (participantes, instrumentos, procedimiento)
5. Resultados (análisis + tablas/figuras)
6. Discusión (interpretación)
7. Referencias
