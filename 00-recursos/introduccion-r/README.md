# Introducción a R para usuarios de jamovi

R permite automatizar análisis, documentar decisiones y reproducir resultados. No necesitas dominar R para empezar con jamovi; este módulo es una extensión gradual.

## Flujo recomendado

1. Explora los datos y realiza el análisis en jamovi.
2. Guarda el archivo `.omv` y documenta las decisiones.
3. Cuando la función o módulo lo permita, revisa el modo de sintaxis/código R. La disponibilidad y el procedimiento dependen del análisis y de los módulos instalados.
4. Ejecuta y valida el código en un entorno R separado antes de usarlo en un informe.

Los nombres de variables, paquetes y opciones pueden variar entre versiones.
