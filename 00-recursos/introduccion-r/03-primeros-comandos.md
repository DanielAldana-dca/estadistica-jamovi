# Primeros comandos de R

```r
2 + 3
sqrt(16)
mean(c(3, 5, 7))
sum(c(2, 4, 6))
?mean
```

- La consola ejecuta instrucciones.
- `#` inicia un comentario.
- Las funciones reciben argumentos entre paréntesis.
- `?mean` abre la ayuda de una función.

Prueba cambiar los números y predice el resultado antes de ejecutar cada línea.
