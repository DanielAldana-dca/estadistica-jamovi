# Instalación de R y RStudio

1. Instala R desde [CRAN](https://cran.r-project.org/).
2. Instala RStudio Desktop desde [Posit](https://posit.co/download/rstudio-desktop/). RStudio es un entorno de trabajo; R es el lenguaje y motor que ejecuta el código.
3. Abre RStudio y escribe `1 + 1` en la consola. Debe aparecer `2`.
4. Crea un proyecto para el curso y guarda scripts con extensión `.R`.

Mantén R actualizado y anota las versiones usadas cuando compartas un análisis.
