# Por qué aprender R

## Ventajas de R sobre jamovi

| Aspecto | jamovi | R |
|---------|--------|---|
| Facilidad | Alta | Media |
| Flexibilidad | Media | Total |
| Reproducibilidad | Buena | Excelente |
| Análisis avanzados | Limitados | Ilimitados |
| Gráficos personalizados | Limitados | Ilimitados |
| Comunidad | Pequeña | Enorme |

## Cuándo dar el salto

- Cuando jamovi se queda corto para tu análisis.
- Cuando necesitas automatizar tareas repetitivas.
- Cuando quieres publicar análisis reproducibles.
- Cuando quieres acceso a métodos avanzados.

## Cómo empezar

1. Aprende lo básico de R.
2. Usa jamovi para explorar.
3. Copia el código R de jamovi.
4. Modifícalo en RStudio.
5. Automatiza lo que puedas.

## Relación con jamovi

jamovi genera código R en segundo plano. Puedes:
- Verlo (modo sintaxis).
- Copiarlo a RStudio.
- Modificarlo y extenderlo.
