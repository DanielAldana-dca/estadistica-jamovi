# Manipulación de datos

## Tipos

| Tipo | Descripción |
|------|-------------|
| **Fabricación** | Inventar datos |
| **Falsificación** | Alterar datos existentes |
| **Omisión selectiva** | Excluir datos sin justificación |
| **Duplicación** | Publicar el mismo estudio varias veces |

## Señales de alerta

- Datos "demasiado perfectos"
- Resultados idénticos en estudios distintos
- Falta de datos crudos disponibles
- Autores que no cooperan con verificaciones

## Cómo prevenirlo

1. **Datos crudos** disponibles públicamente.
2. **Auditoría** por pares.
3. **Reproducibilidad** completa.
4. **Cultura ética** en los equipos de investigación.

## En jamovi

- Guarda siempre el archivo `.omv` original sin modificar.
- Documenta cada transformación.
- Comparte los datos crudos junto con los análisis.
