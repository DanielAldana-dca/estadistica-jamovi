# Buenas prácticas en análisis de datos

## Antes del análisis

1. **Preregistrar** hipótesis y plan de análisis.
2. **Definir** criterios de inclusión/exclusión.
3. **Especificar** variables dependientes e independientes.
4. **Planificar** el tamaño muestral (análisis de potencia).

## Durante el análisis

1. **Explorar** los datos antes de las pruebas.
2. **Verificar** supuestos.
3. **Documentar** cada decisión.
4. **Reportar** todos los análisis, incluso los no significativos.
5. **Distinguir** análisis confirmatorios de exploratorios.

## Después del análisis

1. **Reportar** tamaños del efecto e intervalos de confianza.
2. **Compartir** datos y código.
3. **Reconocer** limitaciones.
4. **Evitar** sobreinterpretar.
5. **Publicar** resultados negativos.
