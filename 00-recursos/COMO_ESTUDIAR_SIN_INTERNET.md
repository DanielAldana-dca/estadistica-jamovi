# Cómo estudiar este curso sin Internet

## Antes de desconectarte

1. Descarga o clona todo el repositorio, no solo el README.
2. Instala jamovi mientras tengas conexión y abre el programa una vez.
3. Si piensas usar módulos adicionales, instálalos previamente. Los análisis principales del curso priorizan funciones de base.
4. Abre algunos CSV y guarda un proyecto `.omv` de prueba.
5. Mantén una copia de seguridad del repositorio y de tus archivos de práctica.

## Qué funciona offline

- Leer todos los Markdown con VS Code, Obsidian, Typora u otro lector local.
- Abrir los CSV con jamovi, una hoja de cálculo o un editor de texto.
- Realizar análisis con funciones ya instaladas.
- Resolver ejercicios, consultar soluciones y redactar informes.

## Qué puede necesitar conexión

- Descargar actualizaciones de jamovi o módulos nuevos.
- Consultar páginas web citadas como bibliografía opcional.
- Obtener actualizaciones del repositorio.

## Organización local recomendada

Crea una carpeta `mi-trabajo/` fuera del contenido didáctico, con subcarpetas `datos-originales/`, `datos-limpios/`, `proyectos-jamovi/`, `informes/` y `notas-personales/`. No edites los CSV originales: crea copias para limpieza.

## Cómo abrir los materiales

Los enlaces son relativos. Si el lector no reconoce un enlace, busca el archivo indicado por su ruta en el explorador de archivos. No dependas de imágenes o enlaces externos para comprender una definición: las instrucciones esenciales están escritas en los documentos locales.
