# Primeros pasos con jamovi

## Objetivo
Aprender a trabajar con datos, elegir tipos de variable, ejecutar un análisis y guardar un proyecto reproducible.

## Orden
1. [Instalación y primera sesión](01_instalacion_primera_sesion.md)
2. [Importar datos y configurar variables](02_importar_variables.md)
3. [Análisis descriptivo guiado](03_analisis_descriptivo_guiado.md)
4. [Guardar y reproducir el análisis](04_guardar_reproducibilidad.md)

## Primer ejercicio
Abre `00-recursos/datasets/datos_estudiantes_sinteticos.csv`, comprueba el tipo de cada columna, ejecuta descriptivos y guarda el proyecto como `primer_analisis.omv`. No interpretes una tabla hasta saber qué variable y qué unidades representa cada fila y columna.
