# Primeros pasos con jamovi

## Objetivo

Aprender a abrir datos, comprobar las variables, ejecutar análisis descriptivos, interpretar resultados y guardar un archivo reproducible. Esta guía complementa el capítulo 3 del libro base.

## Recursos oficiales

- Descargar jamovi: <https://www.jamovi.org/download.html>
- Tutorial oficial: <https://www.jamovi.org/getting-started.html>
- Manual: <https://docs.jamovi.org/>
- Tipos de variables: <https://docs.jamovi.org/data/data_1_overview_data_variables.html>

La interfaz puede cambiar entre versiones e idiomas. Los nombres de pestañas de esta guía son referencias generales; si un menú cambia, consulta la documentación de la versión que tengas instalada.

## Conceptos esenciales

- Una fila suele representar una unidad observada: una persona, una clase, una medición o un experimento.
- Una columna representa una variable.
- El nombre de una variable debe ser claro y estable.
- El nivel de medida y el tipo de dato son ideas diferentes.
- Los resultados suelen aparecer en un panel separado de la tabla de datos.
- El archivo `.omv` puede conservar los datos, el análisis y los resultados para continuar el trabajo después.
