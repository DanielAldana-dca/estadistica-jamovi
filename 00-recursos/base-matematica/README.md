# Matemática básica para estudiar estadística

Este módulo enseña la matemática que necesitarás durante el curso. No exige conocimientos previos avanzados. Estudia los temas en orden y realiza los ejercicios a mano antes de consultar los resultados.

## Orden
1. [Aritmética, fracciones y porcentajes](01_aritmetica_fracciones_porcentajes.md)
2. [Álgebra, fórmulas y notación](02_algebra_formulas_notacion.md)
3. [Ejercicios resueltos](03_ejercicios_resueltos.md)
4. [Formulario rápido](04_formulario_rapido.md)

## Objetivos
- Convertir fracciones, decimales y porcentajes.
- Interpretar razones y proporciones.
- Despejar una variable de una fórmula sencilla.
- Comprender exponentes, raíces, sumatorios e índices.
- Sustituir datos en una expresión sin alterar el orden de las operaciones.
- Interpretar la notación de medias, varianzas y probabilidades.

No necesitas dominar cálculo diferencial para comenzar estadística descriptiva y probabilidad elemental.
