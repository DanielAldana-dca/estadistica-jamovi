# Matemática básica para estudiar estadística

Este módulo es el punto de entrada recomendado si no has estudiado estadística o hace tiempo que no usas matemáticas. No presupone cálculo diferencial ni álgebra avanzada.

## Objetivos

Al finalizar podrás operar con fracciones y porcentajes, interpretar proporciones, usar potencias y raíces, despejar fórmulas simples, leer sumatorios y entender las expresiones que aparecen en un análisis estadístico.

## Antes de comenzar: ideas esenciales

- Una fórmula es una forma compacta de expresar una relación; cada símbolo tiene un significado.
- Una calculadora ayuda con la aritmética, pero no decide qué operación representa la pregunta.
- Mantén las unidades: 2 horas no son 2 minutos, y una nota sobre 100 no es equivalente a una proporción entre 0 y 1.
- Redondea al final del cálculo siempre que sea posible, no después de cada paso.
- Si una respuesta sale fuera de los límites posibles —por ejemplo, una probabilidad de 1.35 o una nota de 140 sobre 100—, revisa el planteamiento.

## Criterio mínimo para continuar

Intenta resolver los ejercicios del módulo sin mirar las soluciones. Un buen criterio práctico es acertar al menos el 80 % y poder explicar los errores. Si no llegas, repite los apartados que te cuesten.
