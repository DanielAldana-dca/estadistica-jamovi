# Instalación de jamovi

## Requisitos

- Windows 10+ / macOS 10.13+ / Linux
- 4 GB RAM mínimo
- 500 MB disco

## Pasos

1. Ve a https://www.jamovi.org/download.html
2. Descarga versión **current**
3. Instala
4. Abre jamovi

## Interfaz

| Zona | Función |
|------|---------|
| Datos | Tabla tipo Excel |
| Análisis | Catálogo de análisis |
| Resultados | Output |

## Atajos

- `Alt` → cinta de opciones
- `Alt + D` → variables
- `Alt + A` → análisis
- `Ctrl + S` → guardar

## Verificar instalación

`Analyses > Exploration > Descriptives` → si funciona, ok.

## Problemas comunes

- No abre → actualiza drivers
- Módulos no cargan → verifica internet
- .omv no abre → reinstala versión current
