# Glosario de estadística y probabilidad

| Término | Definición de trabajo | No confundir con |
|---|---|---|
| Aleatoriedad | Variabilidad cuyo resultado concreto no se conoce de antemano | Falta de reglas |
| Análisis descriptivo | Resumen de los datos observados | Inferencia sobre una población |
| Asimetría | Falta de simetría en una distribución | Tener valores atípicos necesariamente |
| Asociación | Variación conjunta de variables | Causalidad |
| Beta (error tipo II) | No rechazar una hipótesis nula falsa | Valor p |
| Censo | Medición de todas las unidades de una población definida | Muestra |
| Coeficiente de correlación | Medida de fuerza y dirección de asociación lineal | Pendiente de regresión |
| Confusión | Mezcla de efectos por una variable relacionada con exposición y resultado | Mediación |
| Desviación estándar | Raíz cuadrada de la varianza; dispersión en unidades originales | Error estándar |
| Distribución | Patrón de valores y sus frecuencias/probabilidades | Una lista sin contexto |
| Error estándar | Variabilidad de un estimador entre muestras | Dispersión de observaciones individuales |
| Estimador | Regla calculada con datos para estimar un parámetro | Parámetro poblacional |
| Estadístico | Número calculado a partir de una muestra | Parámetro poblacional |
| Evento/suceso | Conjunto de resultados posibles de un experimento | Un único resultado siempre |
| Hipótesis alternativa | Afirmación que representa diferencias/relaciones de interés | Hipótesis que queda probada por defecto |
| Hipótesis nula | Modelo de referencia evaluado por una prueba | Afirmación que siempre es cierta |
| Independencia | Saber un suceso/variable no cambia la distribución del otro | Exclusión mutua |
| Intervalo de confianza | Procedimiento que produce intervalos con cobertura de largo plazo | Probabilidad posterior del parámetro en un intervalo frecuentista observado |
| Media | Suma dividida entre número de observaciones | Mediana |
| Mediana | Valor central ordenado | Media aritmética |
| Muestra | Unidades observadas de una población de interés | Población completa |
| Nivel de medida | Naturaleza y estructura de los valores de una variable | Formato de almacenamiento solamente |
| Parámetro | Cantidad que describe una población/modelo | Estadístico muestral |
| Población | Conjunto definido sobre el que se quiere aprender | Personas de todo el mundo necesariamente |
| Potencia | Probabilidad de detectar un efecto especificado bajo supuestos | Probabilidad de que un resultado sea verdadero |
| Probabilidad condicional | Probabilidad de A dado que B ocurrió | Probabilidad conjunta |
| Valor p | Probabilidad, bajo el modelo nulo y sus supuestos, de un resultado tan extremo o más que el observado | Probabilidad de que H0 sea cierta |
| Varianza | Promedio apropiado de desviaciones cuadráticas | Desviación estándar |
| Variable categórica | Variable que asigna unidades a categorías | Variable numérica continua |
| Variable continua | Medición que conceptualmente puede tomar valores en un intervalo | Variable sin errores de medición |
