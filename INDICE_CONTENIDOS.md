# Índice del paquete de ampliación

## Empezar
- `PAQUETE_LEEME.md`: alcance y cómo usar el paquete.
- `INSTRUCCIONES_INTEGRACION.md`: fusión segura en Git.
- `PLAN_ESTUDIO_12_SEMANAS.md`: calendario sugerido.
- `PROPUESTA_INTEGRACION_README.md`: fragmento para el README actual.

## Módulos
- `00-recursos/base-matematica/`: aritmética, porcentajes, álgebra, símbolos, ejercicios y formulario.
- `00-recursos/primeros-pasos-jamovi/`: instalación, importación, variables, descriptivos y reproducibilidad.
- `01-fundamentos/ampliacion/`: mapa de estadística, muestreo, diseño y variables.
- `02-descriptiva/ampliacion/`: centro, dispersión, z, extremos y gráficos.
- `03-manejo-datos/ampliacion/`: limpieza, faltantes y calidad.
- `04-probabilidad/ampliacion/`: sucesos, conteo, condicionales, Bayes, variables aleatorias, binomial, normal y simulación.
- `05-inferencia/ampliacion/`: muestreo, intervalos, hipótesis, elección de pruebas, efecto, potencia y supuestos.
- `06-modelos/ampliacion/`: correlación, regresión y ANOVA.
- `07-avanzado/ampliacion/`: primera orientación a Bayes.
- `evaluacion-ampliacion/`: diagnóstico, listas de control y soluciones.
- `plantillas/ampliacion/`: estructura de lecciones, informes, diccionario y rúbrica.
- `proyectos/ampliacion/`: cinco proyectos progresivos.
- `00-recursos/datasets-ampliacion/`: seis CSV sintéticos, diccionarios y resultados de referencia.

## Flujo sugerido
1. Matemática básica.
2. Primeros pasos con jamovi.
3. Fundamentos y descriptiva.
4. Limpieza de datos.
5. Probabilidad.
6. Inferencia y selección de pruebas.
7. Modelos.
8. Proyectos.

## Sobre las soluciones
Las soluciones están incluidas para autoestudio. Intenta primero resolver cada actividad; después contrasta el procedimiento. Las cifras de `resultados_referencia.md` corresponden únicamente a los CSV de este paquete y pueden variar si los editas.
