# Inferencia estadística

## Objetivo
Utilizar datos muestrales para estimar cantidades poblacionales y evaluar hipótesis, reconociendo siempre la incertidumbre y los supuestos.

## Regla fundamental
No elijas una prueba solo por el tipo de dato. Considera la pregunta, el diseño, la independencia de las observaciones, la distribución, el tamaño muestral y las condiciones del método.
