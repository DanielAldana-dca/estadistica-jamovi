# Proyectos integradores adicionales

Los proyectos se realizan después de estudiar los conceptos relacionados. Usa los datos sintéticos del paquete y entrega el archivo `.omv`, el informe breve y una bitácora de decisiones.

1. [Proyecto 1: exploración y limpieza](01_exploracion_limpieza.md).
2. [Proyecto 2: probabilidad y simulación](02_probabilidad_simulacion.md).
3. [Proyecto 3: comparación antes-después](03_comparacion_pre_post.md).
4. [Proyecto 4: correlación y regresión](04_correlacion_regresion.md).
5. [Proyecto final: pregunta estadística de principio a fin](05_proyecto_final.md).

Usa la [rúbrica común](../../plantillas/ampliacion/criterios_evaluacion_proyectos.md). Los resultados de los datos sintéticos no deben presentarse como evidencia empírica de una población real.
