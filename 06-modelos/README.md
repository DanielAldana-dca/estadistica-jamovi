# Modelos estadísticos

## Objetivo
Analizar relaciones entre variables y comparar medias de grupos mediante modelos que respondan preguntas concretas.

## Orden de estudio
1. [Correlación y regresión](01_correlacion_regresion.md)
2. [ANOVA y comparaciones entre grupos](02_anova_y_comparaciones.md)
3. [ANOVA factorial](03_anova_factorial.md)

## Precauciones
Correlación no implica causalidad. La regresión describe una relación bajo un modelo y no garantiza predicción fuera del rango observado. ANOVA significativo indica evidencia de que no todas las medias son iguales, pero las comparaciones y el tamaño del efecto ayudan a localizar e interpretar las diferencias.
