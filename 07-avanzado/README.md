# Métodos avanzados

Estos temas deben estudiarse después de dominar descriptiva, probabilidad e inferencia. No son necesarios para comenzar.

## Orden recomendado
1. [Introducción a la estadística bayesiana](01_intro_bayesiana.md)
2. [Análisis factorial](02_analisis_factorial.md)
3. [Estadística bayesiana aplicada](03_estadistica_bayesiana_aplicada.md)

## Qué debes tener claro antes
Comprender distribuciones, incertidumbre, correlación, interpretación de modelos y limitaciones de inferencia. Si estos conceptos aún no son firmes, vuelve a los módulos anteriores.
