# Lección 5: Visualización

## 5.1 Por qué visualizar

Mira los datos antes de calcular. Los gráficos revelan atípicos, patrones y errores.

## 5.2 Histogramas

`Descriptives` → activa "Histogram"

- Eje X: valores
- Eje Y: frecuencia
- Campana → normal
- Cola → sesgada
- Dos picos → bimodal

## 5.3 Boxplots

Muestran:
- Mediana
- Q1 a Q3 (caja)
- Bigotes: 1.5 × IQR
- Puntos: atípicos

**Cómo leerlos:**
- Caja simétrica → simétrica
- Caja desplazada → asimetría
- Puntos aislados → atípicos

## 5.4 Violines

Boxplot + densidad. Muestran forma completa.

## 5.5 Barras

Para categóricas. Altura = frecuencia.

## 5.6 Atípicos

**Regla 1.5 × IQR:**
- Q1 - 1.5×IQR → límite inferior
- Q3 + 1.5×IQR → límite superior

**¿Qué hacer?**
1. Verificar error
2. Investigar caso
3. Reportar
4. Analizar con y sin

## 5.7 Ejemplo

Tiempos de reacción:
- Histograma → sesgado derecha
- Boxplot → atípicos arriba
- Investigar y considerar log

## 5.8 Ejercicios

1. Histogramas de 5 variables
2. Boxplots con atípicos
3. Comparar grupos
4. Identificar bimodales

## 5.9 Resumen

- Visualiza antes de calcular
- Histograma: forma
- Boxplot: mediana, cuartiles, atípicos
- Violín: forma completa
- Barras: categóricas
- Atípicos se investigan
