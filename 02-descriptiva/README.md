# Estadística descriptiva

## Objetivo
Organizar, resumir y representar datos sin confundir una descripción de la muestra con una conclusión sobre una población.

## Orden de estudio
1. [Medidas de centro y dispersión](01_centro_dispersion.md)
2. [Puntuaciones z y valores extremos](02_puntuaciones_z_y_extremos.md)
3. [Cómo seleccionar gráficos](03_seleccion_graficos.md)

## Práctica
Utiliza `00-recursos/datasets/datos_estudiantes_sinteticos.csv`. Identifica el tipo de cada variable, calcula resúmenes, crea gráficos y explica qué información se pierde si solo informas la media.
